# Architecture decisions

Short records of the choices that would otherwise be re-litigated every time
somebody new reads the code. Each one states what the situation was, what was
decided, and what it costs.

|---|----------|

| [3](0003-enter-pastes-rather-than-types.md) | Enter pastes rather than types |
| [4](0004-no-network-by-default.md) | No network by default, and never to an icon service |
| [5](0005-lock-is-a-real-state.md) | Lock is a real state |
